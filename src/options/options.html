How to use

  1. Select an IP, domain, URL or file hash on any page. Defanged forms like 1.2.3[.]4 or hxxps://evil[.]com work too.
  2. Right-click it → 4NTL → pick a provider, or All providers.
  3. Right-click a link → 4NTL: check this link, or a button or card → 4NTL: check what this opens. If it has no address until clicked, click it once: 4NTL catches where it goes and stops it from opening.
  4. Click the 4NTL toolbar icon to check the page you're on, or type 4ntl and a space in the address bar, then paste a link or indicator.
  5. Or press Alt+Shift+L to check the selection everywhere at once.
4NTL v · Private and reserved IP addresses are never sent to any provider.
