Windows processes (EchoTrail)

Select a process name such as svchost.exe, or a path to one, and 4NTL shows how it normally behaves: who usually starts it, what it starts and where it lives, from EchoTrail's 300 million+ real executions. For a service or any other name, right-click → 4NTL → EchoTrail only. The browser asks you to allow api.echotrail.io. While this is off, 4NTL works exactly as before.

How to use

  1. Select an IP, domain, URL or file hash on any page. Defanged forms like 1.2.3[.]4 or hxxps://evil[.]com work too.
  2. Right-click it → 4NTL → Look up “…”, or one provider.
  3. Right-click a link → 4NTL → Check this link.
  4. Nothing to select? Click the 4NTL toolbar icon, or right-click → 4NTL → Type an IP or domain…, then type or paste it. After a result, the magnifier on the card takes you back to look up another. Or type 4ntl and a space in the address bar, then paste a link or indicator.
  5. Or press Alt+Shift+L to check the selection, or whatever the pointer is over, on all providers at once.
