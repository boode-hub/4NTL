4NTL

Threat-intel lookups straight from the right-click menu.

API keys

Keys stay in this browser profile. They are never synced and are only ever sent to the provider they belong to.

Lookup options

days
Only reports from this many past days count toward the abuse score.
minutes
Repeat lookups are instant and don't use API quota. 0 turns this off.

How to use

  1. Select an IP, domain, URL or file hash on any page. Defanged forms like 1.2.3[.]4 or hxxps://evil[.]com work too.
  2. Right-click it → 4NTL → pick a provider, or All providers.
  3. Or press Alt+Shift+L to check the selection everywhere at once.
4NTL v · Private and reserved IP addresses are never sent to any provider.
